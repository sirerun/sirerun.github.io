Zati

Build an AI team you can trust.

Zati is a workspace where you give each AI worker its own responsibilities, limits and budget, so work gets finished and only the decisions that need you come back to you.

  • Zati's source code implements durable workers, task delegation, acceptance checks, and authority and budget limits. Since November 11, 2026, a worker can delegate a task to another worker on the main branch.
  • In a controlled test, a parent task and one delegated specialist both completed and were independently verified, with budgets returned.
  • Zati is being built so chief workers summarize outcomes and escalate only the decisions that need the owner.
